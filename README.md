# .dotfiles

## Install

Clone this repository to $HOME directory and run setup script.

```sh
./setup.sh
```

## Requirements

### Homebrew

```sh
# zsh
brew install pure zsh-autosuggestions zsh-syntax-highlighting

# commands
brew install fd fzf ripgrep thefuck zoxide

# neovim
brew install neovim lazygit markdownlint-cli2 git-delta

# other
brew install herdr gh
```

- karabiner-elements
